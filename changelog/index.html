Changelog

Every operational and source change a stranger would want dated: deploys, pauses, the mirror publication, the K-1 finding. Chain events carry their transaction so the page is checkable, not narrated.

  • 2026-11-12
    security Secret scanning armed: the gate now blocks a key before it reaches the mirror

    The K-1 containment item on /security/ flips OPEN to DONE in this same commit. The pre-push hook runs the allowlist gate, gitleaks and the address-derivation gate unconditionally, and an install failure now ABORTS the mirror build instead of being swallowed by `|| true` — the missing-hook case used to produce a clean-looking tree with no gate on it. The stage is git init-fresh each run, so the hook is re-installed and asserted before every commit, and a CI workflow repeats all of it (plus full-history gitleaks) on the pushed repo. CI's gate was also brought back in sync with the local one: it had drifted loose in three ways — no post-strip branch (so it passed vacuously on the stripped tree), a hand-approximated line selector that could not see `_pk=`/`_pK=`, and no address-drift check. All three are negative-controlled.

  • 2026-11-12
    security Relaunch fired: the fleet moved to a fresh line on unexposed keys

    The K-1 response is a relaunch, not an in-place rotation: the v1 Router treasury and every StreamVault payer/recipient are immutable, and the fees-lane owner is non-transferable, so only a fresh deploy clears them. The new line is owned by a fresh EOA and pays a fresh feeRecipient; the old Base line is paused. See /security/ for what the exposed keys still hold.

  • 2026-11-11
    source dex-sources published: the fleet becomes verifiable from a public tree

    The source mirror behind the site, the contracts and the MCP server went public at one commit. Nine of thirteen live Base contracts compile from it to byte-identical runtimes; two more differ only by constructor immutables. The generator (build.sh, verify.mjs, gen_llms.py, fees.json) is in the open too, closing the 'pages have no source' gap.

  • 2026-11-11
    security K-1 found: private keys in the public mirror

    Round-4 re-audit found 21 exposed identities beside their addresses in the mirror: 12 raw 64-hex keys (18 Markdown key rows, 14 of them KEY-RECORD*.md) and 9 mnemonics (8 mnemonic rows), 9 addresses overlapping both. Containment (rotate owner to a Safe, rotate writer and fees lanes, add secret scanning) is tracked on /security/.

  • 2026-11-10
    note g2a StreamFactory v2.1 deployed (dead-drop fix)

    v2.1 adds receive()/fallback()/rescue(onlyOwner) and a self-funded create, so a bare send to the factory is no longer stranded. Base only.
